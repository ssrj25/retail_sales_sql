# Retail Sales Analysis — SQL

A SQL-based data analysis project that builds a retail sales database, cleans the data, performs exploratory analysis, and answers business questions using SQL queries.

## What It Does

The project works with retail transaction data containing customer, product, sales, date, time, quantity, price, and cost information. SQL queries are used to clean the dataset and derive insights about sales performance, customer behavior, product categories, high-value transactions, and sales timing.

## Key Analysis

- Data validation and null-value handling
- Total sales and order analysis by category
- Customer and demographic analysis
- Top customers by total sales
- Monthly sales trends
- High-value transaction identification
- Category-wise unique customer analysis
- Morning, afternoon, and evening order analysis

## Tech Stack

- Data cleaning
- Exploratory data analysis
