# Retail Sales Analysis — SQL

A SQL-based retail sales analysis project focused on data cleaning, exploratory analysis, and business insights.

## Analysis

- Data cleaning and null-value handling
- Customer and transaction analysis
- Sales by category and gender
- Monthly sales trends
- Top customers by total sales
- Customer counts by category
- Sales by time-of-day shift

## Tech Stack

- SQL
- Relational Database
- Exploratory Data Analysis
